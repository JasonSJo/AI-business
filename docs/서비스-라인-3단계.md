# 서비스 라인 3단계 — 객단가·재구매를 올리는 사다리

> 영상 챕터 "The 3 Levels of Service Delivery"(00:23) + "Building Automations"(01:50) + "Full AI Systems"(02:11) 대응.
> 지금은 랜딩페이지 단일 상품 → 자동화·시스템 티어를 얹어 사다리를 만든다.
> 단, **처음 파는 건 항상 Tier 1**(진입장벽 낮게). 만족한 고객에게 Tier 2·3을 올려 판다.

## Tier 1 — 랜딩페이지 (지금 상품, 진입점)
- **무엇**: 예약받는 모바일 1페이지. 전화·카톡 원터치, 가격·후기·오시는길.
- **납품**: 48시간. 수정 2회.
- **가격**: 49만원 / $490 / ¥69,800. 유지보수 월 3.3만원(선택).
- **목표**: 첫 거래·신뢰 확보. 여기서 리뷰를 받는다.

## Tier 2 — 랜딩 + 자동화 (업셀, 반복 매출)
> 영상의 "automations". 사장님이 반복하는 일을 없애준다 = 매달 돈 낼 이유.
- **무엇** (택1~3 조합):
  - **예약 리마인더 자동 발송** (노쇼 감소) — 예약 전날 문자/카톡 자동 알림
  - **리뷰 요청 자동화** — 방문 다음 날 "리뷰 남겨주세요" 링크 자동 발송 (후기 요청 스크립트 재활용)
  - **문의 자동응답** — 영업시간 외 문의에 자동 답장 + 예약 링크
  - **신규 손님 웰컴 시퀀스** — 첫 방문 후 3통 자동 메일(감사→활용팁→재방문 쿠폰)
- **어떻게 만드나**: 초기엔 지메일 예약발송 + 우리 생성기 조합으로 반(半)수동 → 규모 커지면 GoHighLevel 같은 CRM 도입.
- **가격**: 세팅 30~50만원 + **월 관리 5~9만원** (← 여기서 반복 매출이 생긴다).

## Tier 3 — 풀 시스템 (하이엔드, 소수 고객)
> 영상의 "Full AI Systems". 페이지가 아니라 "손님 유입→예약→재방문" 전체를 설계.
- **무엇**: 멀티페이지 + 예약 시스템 연동 + 간단 CRM(손님 DB) + 자동화 묶음 + 월 리포트.
- **대상**: 지점 2개 이상, 매출 규모 있는 곳.
- **가격**: 150~300만원 세팅 + 월 15~30만원 관리.
- **주의**: Tier 1으로 신뢰를 쌓은 뒤에만 제안. 처음부터 이걸 팔려 하지 말 것.

## 업셀 타이밍 (스크립트)
- Tier 1 납품 후 2주: *"사장님, 페이지 반응 어떠세요? 요즘 예약 리마인더 자동으로 보내드리는 것도 하는데, 노쇼 줄이는 데 효과 좋아요. 관심 있으시면 보여드릴까요?"*
- 재구매·소개가 신규보다 싸다 — Tier 1 고객 명단을 KPI/CRM에 남겨 3개월 뒤 재접촉.

## 지금 당장 할 것
- Tier 2의 "리뷰 요청 자동화"는 이미 우리 자산(후기 요청 스크립트 + 지메일)으로 **바로 팔 수 있음** — 첫 Tier 1 고객이 생기면 곧바로 업셀 제안.
- Tier 3는 문서로만 준비, 실제 구축은 수요 생길 때.
