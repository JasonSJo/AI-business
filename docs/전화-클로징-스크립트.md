# 전화(디스커버리) 클로징 스크립트

> 영상 챕터 "How to Close Clients on Calls"(01:18~01:40) 대응.
> 우리 노선은 "5분 통화 or Loom/이메일 왕복" — 통화가 부담되면 이 구조를 그대로 채팅/메일에 써도 된다.
> 원칙: **파는 게 아니라 진단한다.** 상대가 스스로 "필요하다"에 도달하게.

## 0. 목표
- 5~10분. 상대 상황 파악 → 어울리는 것 제안 → 무료 샘플로 클로징.
- 절대 안 하는 것: 기능 나열, 가격부터 꺼내기, 압박.

## 1. 오프닝 (30초) — 어젠다 + 안심
> "시간 내주셔서 감사합니다. 오늘은 파는 자리가 아니라, [업체명]에 페이지가 실제로 도움이 될지 5분만 같이 보는 자리예요. 아니다 싶으면 솔직히 말씀드릴게요. 편하게 몇 가지만 여쭤볼게요."

## 2. 진단 질문 8개 (심문 아닌 대화)
1. 지금 손님들은 주로 **어디서** [업체명]을 처음 알게 되나요? (인스타 / 지도 / 소개)
2. 그 손님이 예약·문의하려면 지금 **어떤 경로**로 하나요?
3. 그 과정에서 **놓치는 것 같은** 손님이 있다고 느끼시나요?
4. 손님들이 가장 **자주 묻는 질문** 두 개는요? (→ 페이지에 넣을 것)
5. 옆 가게와 **다른 점** 하나만 꼽으면요? (→ 헤드라인 소재)
6. 예약을 받고 싶은 **1순위 행동**은 뭔가요? (전화 / 예약 / 방문)
7. 지금 온라인은 **누가** 관리하시나요? (사장님 직접 / 없음)
8. 이런 걸 **언제까지** 갖추고 싶으세요? (→ 긴급도·예산 신호)

**들을 것(메모)**: "링크가 없다", "인스타만 있다", "예약을 놓친다", "옆 가게로 간다" → 전부 우리 오퍼가 맞는 신호.

## 3. 전환 (자연스럽게 피치로)
> "말씀 들어보니 [손님은 인스타로 오는데, 거기서 예약으로 바로 이어지는 페이지가 없어서] 몇 분은 그냥 스크롤하고 나가는 상황이네요. 딱 그걸 해결하는 게 제 일이에요."

## 4. 오퍼 제시 (상대가 방금 한 말과 연결)
> "[업체명] 손님한테 맞춰서, 모바일 한 페이지에 [6번 답=전화 예약] 버튼을 제일 위에 두고, [4번 답=자주 묻는 질문] 답을 넣고, [5번 답=차별점]을 헤드라인으로 뽑을게요. 48시간이면 됩니다."

## 5. 가격 — 당당하게, 가치 다음에
> "제작은 **49만원**, 수정 2회 포함이에요. (해외: $490 / ¥69,800) 유지보수는 원하실 때만 월 3.3만원이고요."
- 가치를 먼저 그려준 뒤 가격을 말한다. 숨기지 않는다(마케팅 상식 4번).

## 6. 클로징 (부드럽지만 명확하게)
> "제안 하나 드릴게요. 결정 전에 **[업체명] 이름으로 샘플부터 무료로** 만들어 보여드릴게요. 상상으로 판단 안 하셔도 돼요 — 실물 보고 결정하시면 됩니다. 지금 상호랑 사진 두세 장만 주시면 이틀 안에 링크 보내드릴게요. 어떠세요?"
- "네" → 킥오프 설문(킥오프-설문.md) 전달.
- 머뭇 → "부담 없으세요, 샘플은 끝까지 무료예요. 마음에 들 때만 진행합니다."

## 7. 반론 처리 5종 (인정 → 리프레임 → 질문)
| 반론 | 대응 |
|---|---|
| "지금은 좀…" | "그럼요, 바쁘시죠. 그래서 샘플부터 무료로 만들어두는 거예요. 급할 것 없이 보시고 필요할 때 쓰시면 돼요. 상호만 주시겠어요?" |
| "인스타로 충분한데요" | "인스타 잘 하고 계세요. 다만 프로필 링크 누른 손님이 갈 곳이 없으면 거기서 끊겨요. 그 한 페이지만 채우는 거예요." |
| "비싼데요" | "손님 한두 명만 더 예약해도 회수돼요. 그리고 마음에 들 때만 결제라 리스크가 없어요. 샘플부터 볼까요?" |
| "직접 만들 수 있을 것 같은데" | "가능하세요. 다만 48시간 vs 주말 내내를 비교해 보세요. 그 시간에 사장님은 가게를 보시는 게 낫죠." |
| "다른 데도 알아보는 중" | "좋아요, 비교는 당연해요. 그래서 저는 샘플을 무료로 먼저 드려요 — 견적서만 받는 다른 곳이랑 실물로 비교해 보세요." |

## 8. 통화 후
- 24시간 내 샘플 제작 → 링크 전달.
- KPI 대시보드에 "통화→샘플" 단계 기록.
