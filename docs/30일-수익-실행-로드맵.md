# 30일 첫 수익 실행 로드맵

> 기반 영상: **Start a 1-Person Business with Claude (4 HOUR COURSE 2026)**
> ([YouTube](https://www.youtube.com/watch?v=mKyaNr3jK-E))
> 목표: **30일 안에 첫 유료 고객 확보 → 90일 안에 월 $2,000~3,000(생활비 커버) 도달**

이 문서는 영상의 8단계 프레임워크를 "오늘부터 뭘 할지"까지 내려온 실행 계획서다.
코드/툴을 만들기 **전에** 방향을 확정하기 위한 문서이며, 각 단계는 실제로 복사해서 쓸 수 있는 템플릿을 포함한다.

---

## 0. 핵심 전제 (영상의 진짜 메시지)

영상이 반복해서 강조하는 세 가지. 이걸 놓치면 나머지는 무의미하다.

1. **AI는 실력이 아니다. 마케팅·영업이 실력이다.**
   대부분의 사람이 실패하는 이유는 AI를 못 써서가 아니라, 하루 4시간 영업을 안 해서다.
2. **첫 고객은 돈이 아니라 후기·신뢰·경험치(reps)를 사는 것이다.**
   무료/저가로 시작해도 괜찮다. 결과물과 증거를 쌓는 게 먼저.
3. **병목을 하나씩 찾아 없앤다.** 리드 → 미팅 → 딜리버리 → 다시 리드.
   지금 막힌 지점 하나에만 집중한다.

> **한 줄 요약:** 좁은 서비스 하나를, 명확한 타겟에게, 매일 꾸준히 판다.

## 1. 무엇을 팔 것인가 (Offer)

"AI 뭐든 다 해드립니다"는 안 팔린다. **한 문장으로 설명되는 좁은 서비스** 하나로 시작한다.

### 추천 진입 서비스 (하나만 고른다)

| 서비스 | 고객이 얻는 결과 | 제작 난이도 | 진입 가격 |
|---|---|---|---|
| **A. 소상공인 랜딩페이지 제작** | "24시간 안에 예약/문의 받는 웹사이트" | 낮음 | ₩30만~80만 (건당) |
| **B. AI 콜드 이메일/DM 아웃리치 대행** | "매주 예약된 미팅 3~5건" | 중간 | ₩50만~150만 (월) |
| **C. 반복 업무 자동화 (문서·리포트·데이터)** | "매주 10시간 절약" | 중간 | ₩40만~120만 (건/월) |
| **D. AI 콘텐츠 파이프라인** (블로그·SNS) | "매주 콘텐츠 8개 자동 생산" | 낮음 | ₩40만~100만 (월) |

**추천: A(랜딩페이지) 또는 D(콘텐츠)로 시작.** 결과물이 눈에 보이고, 하루 만에 만들 수 있어 후기 확보 속도가 빠르다.

### Offer 한 문장 만들기 (빈칸 채우기)

> "저는 **[타겟]** 을 위해 **[결과]** 를 **[기간]** 안에 만들어 드립니다. 마음에 안 들면 환불합니다."

예시:
- "저는 **동네 병원·미용실** 을 위해 **예약 문의를 받는 랜딩페이지** 를 **48시간** 안에 만들어 드립니다."
- "저는 **1인 자영업자** 를 위해 **인스타 콘텐츠 8개/주** 를 자동으로 만들어 드립니다."

## 2. 누구에게 팔 것인가 (타겟)

돈 있고, 문제가 명확하고, 접근 가능한 집단을 고른다.

**좋은 타겟의 조건**
- ✅ 이미 돈을 쓰고 있다 (광고를 돌리거나, 직원을 고용 중)
- ✅ 문제가 급하고 명확하다
- ✅ 리스트업이 가능하다 (네이버 지도, 인스타, 링크드인에서 100개 뽑을 수 있음)

**시작하기 좋은 니치 예시**
- 지역 서비스업: 병원, 치과, 필라테스/PT, 미용실, 인테리어, 부동산
- 스몰 브랜드: 스마트스토어 셀러, 공방, 카페, 로컬 F&B
- 전문직 1인: 세무사, 노무사, 코치, 강사

> **하지 말 것:** 첫 달에 니치를 3번 바꾸지 마라. 하나 정해서 100명에게 연락한 뒤 판단한다.

## 3. 가격 전략

| 단계 | 목표 | 가격 |
|---|---|---|
| 1~3번째 고객 | 후기·사례 확보 | **무료 또는 원가(₩10만 내외)** — "후기 써주시는 조건" |
| 4~8번째 고객 | 현금흐름 만들기 | 정상가의 50~70% |
| 9번째~ | 월 $2-3k 도달 | 정상가 + 인상 |
| 안정화 후 | 고객 수 줄이고 단가↑ | 가격 인상 → 저단가·까다로운 고객 정리 |

**핵심:** 처음엔 싸게 받되 **결과와 후기**를 반드시 받아낸다. 후기 3개가 다음 10명을 데려온다.

## 4. 어디서 고객을 찾는가 (채널)

하루 **4시간 아웃리치**가 이 비즈니스의 심장이다. 채널 1~2개만 골라 집중한다.

| 채널 | 방식 | 하루 목표량 |
|---|---|---|
| **콜드 이메일** | 네이버지도/구글맵에서 이메일 수집 → 개인화 발송 | 20~40통 |
| **인스타 DM** | 타겟 계정에 가치 제안 DM | 20~30건 |
| **링크드인** | 연결 요청 + 메시지 | 15~25건 |
| **로컬 직접방문/전화** | 동네 매장 직접 컨택 | 5~10곳 |

**측정:** 발송 100건 → 응답 5~15건 → 미팅 2~5건 → 계약 1~2건 (초기 기준, 시간이 지나며 개선됨)

## 5. 30일 일별 실행 계획

### Week 1 — 세팅 & 첫 결과물 (증거 만들기)

| Day | 할 일 | 산출물 |
|---|---|---|
| Day 1 | OS 세팅: 폴더 구조 + Claude Code + GitHub 백업. Offer 한 문장 확정 | 저장소 + Offer |
| Day 2 | **가짜 데모 사업**용 랜딩페이지/콘텐츠 샘플 1개 제작 후 무료 배포 | 포트폴리오 1호 |
| Day 3 | 타겟 니치 확정 + 잠재고객 100명 리스트업 (이름·연락처·한줄메모) | 리드 시트 100개 |
| Day 4 | 프리랜서 프로필 작성 (크몽/숨고/링크드인) + 콜드 템플릿 작성 | 프로필 + 템플릿 |
| Day 5 | 첫 콜드 캠페인 발송 (20~40건) | 발송 로그 |
| Day 6~7 | 응답 대응 + 데모 2호 제작 + 리스트 100 → 200 확장 | 후기용 사례 2개 |

### Week 2 — 아웃리치 본격화 (병목: 리드)

- 매일 콜드 발송 30건+ / 응답 전원 24시간 내 회신
- 미팅 잡히면 **무료·저가 조건으로 첫 고객** 확보 목표
- 응답률 낮으면 → 메시지 첫 문장(훅) A/B 테스트

### Week 3 — 첫 딜리버리 (병목: 딜리버리)

- 첫 고객 결과물 제작 → **약속보다 빠르게, 기대보다 좋게** 전달
- 완료 즉시 **후기 요청** (텍스트 + 가능하면 결과 스크린샷)
- 후기를 프로필/포트폴리오에 반영 → 다음 발송에 "실제 사례" 첨부

### Week 4 — 반복 & 유료 전환 (병목: 다시 리드)

- 후기 기반으로 발송량 유지, 이번엔 **정상가 50~70%** 제시
- 유료 고객 1~2건 클로징이 30일 목표
- 월말 리뷰: 발송/응답/미팅/계약 숫자 계산 → 다음 병목 식별

> **30일 성공 기준:** 유료(또는 후기 확보된) 고객 최소 1명 + 재현 가능한 아웃리치 루틴.

## 6. 복사해서 쓰는 템플릿

### 6-1. 콜드 이메일 (국문)

```
제목: {업체명} 예약 문의 늘리는 방법 (2분)

안녕하세요, {대표님/담당자님}.
{업체명} 인스타를 보고 연락드립니다. {구체적 관찰 한 줄 — 예: "리뷰가 좋은데 예약 링크가 없어서"}.

동네 {업종} 대상으로 문의를 받는 랜딩페이지를 48시간 안에 만들어 드리고 있습니다.
방금 만든 예시입니다: {링크}

관심 있으시면 무료로 하나 만들어 보여드릴게요. 마음에 안 들면 안 쓰시면 됩니다.
5분 통화 가능하실까요?

{이름} 드림
```

### 6-2. 인스타 DM (짧게)

```
안녕하세요! {업체명} 잘 보고 있어요 👀
{업종} 사장님들 예약 문의 받는 페이지 만들어 드리는데,
샘플 하나 무료로 만들어 드릴게요. 보시고 결정하시면 됩니다.
혹시 관심 있으실까요?
```

### 6-3. 후기 요청 메시지

```
{대표님}, 결과 마음에 드셨다니 다행입니다 🙏
혹시 두세 문장으로 후기 남겨주실 수 있을까요?
"어떤 문제가 있었고 → 어떻게 해결됐는지" 위주면 큰 도움이 됩니다.
허락해주시면 다른 사장님들께 사례로 소개하겠습니다.
```

## 7. 추적 지표 (매일 기록)

| 지표 | 주간 목표 (초기) |
|---|---|
| 아웃리치 발송 수 | 150~200 |
| 응답 수 | 10~20 |
| 미팅 수 | 3~8 |
| 계약 수 | 1~2 |
| 완료된 딜리버리 | 1~3 |
| 확보한 후기 | 1~3 |

> 매주 이 숫자를 보고 **가장 낮은 전환 구간 = 이번 주 병목**에 집중한다.

## 8. 흔한 실패 이유 (영상 기준)

- ❌ AI 배우기·툴 세팅에만 몇 주를 쓰고 영업을 안 함 → **Day 1부터 발송**
- ❌ 니치를 계속 바꿈 → **100명 연락 후 판단**
- ❌ 후기를 안 받음 → **모든 완료 건에서 무조건 요청**
- ❌ 처음부터 비싸게 팔려 함 → **초기엔 증거 확보가 우선**
- ❌ 완벽한 결과물에 집착 → **빠르게 전달하고 피드백으로 개선**

## 9. 다음 단계 (이 로드맵 이후 만들 것)

이 로드맵이 확정되면, 실행을 가속할 도구를 이 저장소에 만든다:

1. **리드 수집 → 콜드 이메일 자동 생성기** (개인화 메시지 대량 생성)
2. **랜딩페이지 템플릿 생성기** (고객 정보 입력 → 사이트 자동 생성)
3. **아웃리치 추적 대시보드** (발송/응답/미팅/계약 KPI)

> 어떤 도구부터 만들지는 위 서비스 선택(A~D)에 따라 결정한다.
