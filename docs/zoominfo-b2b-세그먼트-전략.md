# ZoomInfo 활용 — 상향 세그먼트(B2B) 전략

> ZoomInfo 연결로 새 세그먼트가 열렸다: **직원·매출이 있는 소상공인~중소기업**.
> 1인 네일샵·카페(ZoomInfo에 거의 없음)와 달리, **메디스파·부티크 피트니스·클리닉·에이전시·전문서비스**는 데이터가 풍부하고 객단가가 높다.

## 0. 컴플라이언스 (반드시 지킬 것)
ZoomInfo AUP는 **대량 추출로 콜드 리스트 만들기를 금지**한다. 우리는:
- **개별 리서치 쿼리**로만 사용 (한 번에 소수, 특정 회사 파악·개인화 목적).
- 발송은 기존과 동일 **CAN-SPAM 준수**(발신자 실명·소재지, 수신거부, 거부 시 재발송 금지) → 합법적 근거(legitimate interest B2B) 확보.
- 데이터 최소화: 필요한 것만 조회·보관. 리드 CSV는 gitignore(커밋 금지).

## 1. 왜 이 세그먼트인가
- **객단가 상향**: 동네 가게 49만원 → 메디스파/클리닉은 **캠페인 랜딩 $990~ / 시리즈 계약** 가능.
- **데이터로 개인화**: 원장 이름·경력·시술·소셜·창업연도까지 나와 콜드메일 개인화 품질이 급상승(예: "Dr. [원장], 20년 경력의 [시술] 전문…").
- **의사결정자 접근**: 회사 → 담당자(원장/마케팅) 개별 조회 가능.

## 2. 오퍼 각도 전환 (중요)
이들은 **이미 웹사이트가 있다.** "사이트 없으시죠" 오퍼는 안 통한다. 각도를 바꾼다:
- ❌ "You have no page"
- ✅ **"당신 사이트는 있지만, 특정 프로모션/신규 시술을 광고로 돌릴 때 트래픽이 홈으로 흩어진다. 그 광고·인스타 클릭을 받아내는 **전용 캠페인 랜딩 페이지**를 만들어 드린다."**
- 메디스파는 상시 프로모션(보톡스 특가, 신규 레이저 런칭, 시즌 패키지)을 돌린다 → 프로모션마다 전용 랜딩이 필요 = **반복 수요**.

## 3. 리서치 → 아웃리치 워크플로 (개별, 소량)
```
1. search_companies  — 세그먼트+지역+규모로 소수 조회 (예: med spa, US, 10~49명)
2. enrich_companies  — 관심 회사만 상세(설명·전화·소셜·원장)
3. search_contacts / get_recommended_contacts — 그 회사의 의사결정자(원장·오너·마케팅) 1명 개별 조회
4. 개인화 콜드메일 1통 (CAN-SPAM) — 캠페인 랜딩 각도, 무료 샘플 오퍼
5. KPI에 "MEDSPA" 메모로 분리 추적
```
- 하루 소량(개별 리서치 원칙). 대량 덤프 금지.

## 4. 타겟 세그먼트 후보 (ZoomInfo 데이터 풍부 + 우리 데모 통함)
| 세그먼트 | 오퍼 각도 | 데모 |
|---|---|---|
| 메디스파/에스테틱 | 프로모션 캠페인 랜딩 | (신규 제작 권장) |
| 부티크 피트니스/필라테스(체인) | 체험 예약 전환 랜딩 | studio-en |

| 로컬 에이전시(그들의 클라이언트용 화이트라벨) | 하도급 제작 파트너 | 전체 |

## 6. 참고: Apollo와 병행
Apollo.io(연결됨, 이 채팅에서 켜면 사용 가능)도 같은 역할. ZoomInfo는 기업 데이터·의사결정자 정확도가 강하고, Apollo는 크레딧·검색이 유연. **둘 다 "개별 리서치"로만** 쓴다.
