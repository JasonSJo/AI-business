# 광고 세팅 가이드 — Jason's Consulting

> 목표: 광고로 "랜딩페이지가 필요한 사장님"의 문의를 만든다.
> 원칙: **아웃리치(콜드 발송)가 주력, 광고는 증폭기다.** 광고는 작게 시작해서
> 문의당 비용(CPL)이 검증된 뒤에만 예산을 늘린다.

착륙 페이지(광고 클릭 후 도착지)는 이미 있다: **https://jasonsjo.github.io/AI-business/**

## 0. 시작 전 체크 (이것부터 안 하면 광고비가 샌다)

- [ ] 착륙 페이지에 **연락 수단**이 있어야 한다. 현재 허브의 CTA는 이메일뿐 —
      광고를 켜기 전에 **카카오톡 채널**을 만들고 허브 CTA에 연결할 것 (아래 1단계).
- [ ] KPI 대시보드에 광고 유입을 기록할 규칙 정하기: 광고 문의는 발송 0 / **응답 +1**로 기록, 메모에 "광고".
- [ ] 하루 예산 상한 설정 (시작: **일 10,000~20,000원**). 상한 없이 켜지 말 것.

## 1. 카카오톡 채널 (무료, 30분) — 광고 이전의 필수 인프라

1. **카카오톡 채널 관리자센터** (center-pf.kakao.com) → 새 채널 만들기
2. 채널명: `Jason's Consulting` / 검색 ID: 예) `@jasonsconsulting`
3. 채널 URL(`http://pf.kakao.com/_채널ID`)을 받으면 알려달라 —
   허브·데모 4종의 카톡 버튼(`kakao_url`)에 일괄 반영해 재배포한다.
4. 소상공인 사장님들은 이메일보다 **카톡 문의 전환율이 압도적으로 높다.**

## 2. 채널 우선순위 (이 순서대로 켠다)

| 순위 | 채널 | 왜 | 시작 예산 |
|---|---|---|---|
| **1** | **네이버 검색광고** (파워링크) | "홈페이지 제작"을 *검색하는* 사장님 = 구매 의도 최상 | 일 10,000원 |
| **2** | **인스타그램/메타 광고** | 지역 사장님 타겟팅 + 데모 이미지가 잘 먹히는 매체 | 일 10,000원 |
| 3 | 당근 비즈니스 광고 | 로컬 소상공인 밀집, 저렴 | 일 5,000원 |
| 보류 | 구글 검색 | 국내 소상공인 검색량이 네이버 대비 적음 | 나중에 |

**동시에 켜지 말 것.** 네이버 2주 → 성과 보고 메타 추가.

## 3. 네이버 검색광고 세팅 (1순위)

**계정**: searchad.naver.com 가입 → 사업자 인증(사업자등록 후) 또는 개인 가능 → 비즈머니 충전 (5만원부터)

**캠페인 구조** (단순하게):
```
캠페인: 파워링크 — 랜딩페이지 제작 (일예산 10,000원)
└ 광고그룹 1: 제작 의도 키워드
└ 광고그룹 2: 업종 키워드 (성과 확인 후)
```

**키워드 (광고그룹 1 — 이것만으로 시작)**
- 핵심: `홈페이지제작`, `랜딩페이지제작`, `홈페이지제작업체`, `소상공인홈페이지`, `가게홈페이지만들기`, `1인샵홈페이지`
- 저가 롱테일: `미용실홈페이지`, `필라테스홈페이지`, `카페홈페이지제작`, `병원랜딩페이지`
- **제외 키워드**: `무료홈페이지만들기`(직접 만들려는 사람), `홈페이지제작배우기`, `취업`, `강의`

**광고 문구 (복붙용 — 심사 기준상 과장 표현 불가)**

```
[제목] 예약받는 랜딩페이지, 48시간 제작
[설명] 소상공인 전문. 모바일 예약버튼·후기·지도까지 한 페이지.
      내 가게 이름으로 무료 샘플부터 확인하세요.
```
```
[제목] 홈페이지 없이 예약 놓치고 계신가요?
[설명] 병원·미용실·카페 전문 랜딩페이지. 48시간 완성,
      무료 샘플 먼저 보고 결정하세요.
```

**URL**: 표시 URL·연결 URL 모두 허브(`jasonsjo.github.io/AI-business/`) — 연결 URL에는 UTM을 붙인다(6장).

## 4. 인스타그램/메타 광고 세팅 (2순위)

**계정**: 인스타 비즈니스 계정 전환 → Meta 광고 관리자 (business.facebook.com) → 결제수단 등록

**캠페인**: 목표 = **트래픽** (초기) → 문의가 잡히기 시작하면 **전환/메시지** 로 변경
- 타겟: 대한민국 · 25–55세 · 관심사 "소기업, 자영업, 창업, 마케팅" · 지역은 처음엔 전국(좁히면 비싸짐)
- 노출 위치: 자동
- 일예산 10,000원

**크리에이티브 (이미 있는 자산 재활용)**
- 이미지: 데모 4종 스크린샷 (필라테스/치과/살롱/카페 히어로 화면) — 4장 슬라이드(캐러셀)로
- 본문 카피:
```
사장님, 아직 인스타 DM으로만 예약 받으세요?
예약 버튼 달린 한 페이지, 48시간이면 됩니다.
병원·미용실·카페·필라테스 데모 먼저 구경하세요 👇
내 가게 버전 샘플은 무료로 만들어 드립니다.
```
- 헤드라인: `48시간 완성 · 무료 샘플 먼저`

## 5. 예산·성과 판단 (2주 룰)

- 2주 = 약 15만원 소진 후 판단한다. 그 전에 껐다 켰다 하지 않는다.
- **판단 지표: CPL (문의 1건당 비용)**
  - 문의 5건 미만 / 15만원 → 광고 문구·키워드 교체 후 2주 더
  - CPL 3만원 이하 → 예산 2배 증액
  - CPL 5만원 초과 지속 → 채널 중단, 아웃리치에 시간 재투자
- 근거: 건당 30~80만원 상품이므로 CPL 3만원이면 문의 10건 중 2건만 계약해도 남는다.
- **모든 광고 문의는 KPI 대시보드에 기록** (응답 +1, 메모 "광고-네이버" / "광고-메타") — 주간 병목 진단에 광고 성과가 함께 잡힌다.
