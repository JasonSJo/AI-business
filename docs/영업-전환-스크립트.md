# 영업 전환 스크립트 — 무료 샘플에서 결제까지

> 가장 얼어붙기 쉬운 순간: "샘플 좋네요!" 다음에 가격을 말하는 순간.
> 아래 문장을 그대로 쓰면 된다. 원칙은 하나 — **가격을 사과하지 않는다.**

---

## 1. 샘플 보낼 때 (기대 심기)

```
{대표님}, 말씀하신 대로 {업체명} 샘플 만들어봤습니다: {샘플링크}

폰에서 열어보시면 하단에 전화·카톡 버튼이 바로 보이실 거예요.
편하게 보시고, 바꾸고 싶은 부분 알려주세요.
```
→ 이 단계에서 가격 얘기를 먼저 꺼내지 않는다. 반응부터 받는다.

## 2. "좋네요" 반응이 오면 (전환의 순간)

```
다행입니다! 그럼 이대로 진행해 드릴게요.

실제 오픈까지는:
· 사진·문구를 {업체명} 실제 정보로 교체
· 전화·카톡 버튼 실제 연결 + 도메인 배포
· 오픈 후 7일 무상 수정

제작비는 50만원이고, 선금 25만 입금되면 48시간 안에 완성본 드립니다.
계좌: 카카오뱅크 3333-17-4017377 (조상래)
```
→ 가격 말하고 **침묵한다.** 먼저 말을 더 얹으면 깎아달라는 신호로 읽힌다.

## 3. 이의 대응 3종

**"비싸네요"**
```
그렇게 보실 수 있어요. 다만 업체 통해서 하면 보통 100만원 이상, 2~3주 걸립니다.
저는 48시간에 절반 가격이고, 마음에 안 드시면 잔금은 안 주셔도 됩니다.
이번 달은 후기 받는 조건으로 40만원까지 해드릴 수 있어요. 어떠세요?
```
→ 최대 할인 한도는 정가의 20%. 그 밑으로 내려가지 않는다.

**"생각해볼게요"**
```
네, 편하게 보세요. 샘플 링크는 일주일 뒤에 내려갑니다.
그 전에 결정해주시면 지금 구성 그대로 진행해 드릴게요.
```
→ 마감을 만든다. 실제로 7일 뒤 링크를 내린다(빈말 금지).

**"무료로 계속 쓰면 안 되나요?"**
```
샘플은 시안이라 실제 연락처 연결과 배포가 안 돼 있어요.
실제로 문의를 받으려면 완성 작업이 필요합니다.
대신 첫 달 유지보수(3.3만원)는 무료로 넣어드릴게요.
```

## 4. 입금 후 → [결제 가이드](결제-세팅-가이드.md)의 입금 확인 회신 + 계약서

- 30만원 이상 건은 [계약서](../tools/invoice/계약서.html) 출력 → 서명 (분쟁 방지, 2분)
- 납품 시 [납품 체크리스트](납품-체크리스트.md) 통과 필수

## 5. 납품 직후 (후기 + 유지보수 업셀)

```
{대표님}, 오픈 완료됐습니다: {실제링크}

두 가지만 부탁드려요:
1. 두세 문장 후기 (어떤 문제가 → 어떻게 해결됐는지)
2. 지인 사장님 중 필요하신 분 계시면 소개 — 소개 건은 10% 할인해 드립니다

그리고 월 3.3만원 유지보수(문구·이미지 수정 월 2회, 점검 포함) 넣어드릴까요?
첫 달은 무료입니다.
```
