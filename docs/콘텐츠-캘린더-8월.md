# 8월 콘텐츠 캘린더 — 인스타그램 릴스 + 유튜브 쇼츠

> 캠페인 컨셉: **"48시간의 기록"** — 말로 설명하지 않고 만드는 과정을 그대로 보여준다.
> 비주얼 무드: 온기 기하학 (크림 배경 + 파인 그린 + 클레이) · 화면 녹화 + 타임랩스 중심.
> 핵심 메시지: **"무료 샘플 먼저. 결제는 마음에 들 때만."**

## 콘텐츠 기둥 4개

| 기둥 | 목적 | 비중 |
|---|---|---|
| 🎬 제작 과정 | 신뢰 (실력을 실물로 증명) | 40% |
| 📚 사장님 수업 | 교육 (저장 유도) | 30% |
| 🖼 데모 쇼케이스 | 판매 (11종 데모 활용) | 20% |
| 💬 결과·후기 | 신뢰 (고객 생기면 즉시 추가) | 10% |

## 주 3회 · 4주 플랜 (월·수·금 업로드)

### 1주차 — 존재 알리기
- **월 (제작 과정)** 릴스: "랜딩페이지 48시간 타임랩스" — 빈 화면→완성 데모 15초 압축. 훅: "이거 만드는 데 얼마 걸릴 것 같으세요?"
- **수 (사장님 수업)** 캐러셀: "예약 놓치는 가게의 공통점 5가지" — 저장 유도형
- **금 (데모 쇼케이스)** 릴스: 네일샵 데모(달네일) 폰 화면 스크롤 — 훅: "네일샵 사장님, 프로필 링크에 이거 하나면 됩니다"

### 2주차 — 교육으로 신뢰 쌓기
- **월 (사장님 수업)** 릴스: "리뷰 200개인데 예약 링크가 없다?" — 실제 관찰 패턴 소개
- **수 (제작 과정)** 릴스: "카페 사장님 페이지에 꼭 넣는 3가지" — 데모 화면 캡처로 설명
- **금 (데모 쇼케이스)** 캐러셀: 업종별 데모 6컷 모음 — "당신 업종도 있습니다"

### 3주차 — 오퍼 밀기 (판매 주간)
- **월 (제작 과정)** 릴스: "무료 샘플이 진짜 무료인 이유" — 비즈니스 모델 솔직 설명. 훅: "사기 아니냐고 물으셔서요"
- **수 (사장님 수업)** 캐러셀: "샘플 요청 전에 준비할 것 딱 2가지 (업체명, 사진)"
- **금 (오퍼)** 릴스: 기존 15초 광고 영상 재게시 + "이번 달 3자리 남았습니다" (실제 캐파 기준으로만)

### 4주차 — 글로벌 + 증거
- **월 (데모 쇼케이스)** 릴스: 일본어 데모 스크롤 — "일본 사장님 페이지도 만듭니다" (국내 신뢰도 상승 효과)
- **수 (사장님 수업)** 캐러셀: "미국 소상공인은 예약 페이지를 이렇게 씁니다" — 벤치마크 소개
- **금 (결과·후기)** 첫 고객 후기 or 샘플 제작 후기 — 없으면 "지금까지 만든 데모 11종 회고"
