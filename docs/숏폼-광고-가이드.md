# 숏폼(쇼츠·릴스) 광고 가이드 — Jason's Consulting

> 유튜브 쇼츠 + 인스타 릴스로 "랜딩페이지가 필요한 사장님"에게 도달한다.
> 숏폼의 역할: **무료 리드 채널 + 신뢰 자산.** 콜드 DM을 받은 사장님이 프로필을
> 확인했을 때 영상이 쌓여 있으면 응답률이 달라진다.

---

## 0. 지금 바로 올릴 수 있는 완성 영상 1편

**`tools/video-ad/jasons-ad-15s.mp4`** — 15초 · 1080×1920 · 30fps (릴스/쇼츠 규격)

구성: 훅("사장님 가게, 검색하면 뭐가 나오나요?") → 데모 4종 폰 화면 퍼레이드 →
48시간 완성·예약 버튼·무료 샘플 → CTA("프로필 링크 👆")

- 업로드 시 **프로필 링크를 허브**(`jasonsjo.github.io/AI-business/?utm_source=organic&utm_medium=shorts`)로 설정할 것.
- 데모를 바꾸면 재생성 가능: 저장소 루트에서 `python3 -m http.server 8896` 실행 후 `node tools/video-ad/record.cjs`
  (화면 구성 수정은 `tools/video-ad/ad-15s.html`).

**캡션 (복붙용)**
```
검색해도 안 나오는 가게는, 없는 가게랑 같습니다.
예약 버튼 달린 한 페이지 — 48시간이면 됩니다.
내 가게 이름으로 무료 샘플부터 받아보세요 (프로필 링크)

#소상공인 #자영업 #홈페이지제작 #랜딩페이지 #마케팅 #사장님 #카페창업 #미용실 #필라테스 #치과
```

## 1. 채널 세팅 (1시간)

- [ ] **인스타그램**: 프로페셔널(비즈니스) 계정 전환 → 프로필: "예약받는 랜딩페이지, 48시간 ⏱ / 무료 샘플 ↓" + 허브 링크
- [ ] **유튜브**: 채널 생성 (같은 핸들) — 쇼츠는 인스타에 올린 영상 그대로 재업로드
- [ ] 프로필 링크는 반드시 UTM 붙은 허브 URL (성과 구분용)

## 2. 콘텐츠 전략 — 주 3편, 세 가지 유형 순환

| 유형 | 비중 | 예 |
|---|---|---|
| **제작 과정** (신뢰) | 주 1 | 화면녹화 타임랩스: 빈 화면 → 완성 페이지 |
| **문제 제기** (도달) | 주 1 | "사장님들이 광고비보다 먼저 써야 하는 것" |
| **오퍼** (전환) | 주 1 | 완성 영상(0번) 또는 무료 샘플 오퍼 |

원칙: **과장 금지, 지어낸 실적 금지.** 실제 계약·후기가 생기면 그때 실화 스토리형을 추가한다(가장 강력한 유형이므로 후기를 모으는 이유가 하나 더 생긴다).

## 3. 촬영용 대본 4편 (30초 내외, 그대로 읽으면 됨)

> 촬영 팁: 폰 전면카메라, 얼굴 또는 화면녹화. 첫 문장은 자막으로 크게.
> 한 문장마다 컷을 나누면(점프컷) 시청 유지율이 오른다.

### ① 화면녹화형 — "4분 만에 만들어 봤습니다"
*(화면: 실제 생성기 실행 → 완성 페이지 타임랩스. 얼굴 없이 가능)*
```
치과 랜딩페이지, 얼마나 걸리는지 재봤습니다.
보통 업체에 맡기면 2주에 백만 원.
그런데 저는 도구를 직접 만들었습니다.
가게 정보를 넣고—             (화면: config 입력)
실행하면—                      (화면: 생성)
예약 버튼까지 달린 페이지가 나옵니다.  (화면: 완성 스크롤)
그래서 48시간이면 충분하고, 샘플은 공짜로 드립니다.
마음에 안 들면? 안 쓰시면 됩니다.
```

### ② 문제 제기형 — 렌즈: "광고비가 아니라 착륙 지점이 문제"
```
사장님들, 광고 늘리기 전에 이것부터 보세요.
광고 누른 손님이 도착하는 곳이 인스타 프로필이면—
전화번호 찾다가 그냥 나갑니다.
광고비가 아니라 착륙 지점이 새는 겁니다.
예약 버튼 하나 달린 한 페이지면 그 손님이 문의가 됩니다.
프로필에 업종별 예시 있습니다. 내 가게 버전은 무료로 만들어 드려요.
```

### ③ Before/After형
*(화면: 예약 링크 없는 흔한 인스타 프로필 → 데모 페이지 스크롤)*
```
이 가게, 리뷰도 좋고 사진도 좋습니다.
그런데 예약하려면? DM 보내고 기다려야 합니다.    (Before 화면)
같은 가게에 페이지 하나만 붙이면—                 (After 화면)
전화·카톡·예약이 버튼 세 개로 끝납니다.
손님은 기다려주지 않습니다.
48시간이면 됩니다. 샘플은 무료.
```

### ④ 오퍼형 — "조건은 하나"
```
사장님 가게 랜딩페이지, 무료로 만들어 드립니다.
조건은 하나입니다.
보시고 마음에 들면, 그때만 결제하시면 됩니다.
마음에 안 들면 그냥 가지세요. 청구 안 합니다.
왜 이렇게 하냐고요?
페이지를 보면 대부분 계약하시거든요.
프로필 링크에서 업종별 예시 먼저 확인하세요.
```

## 4. 운영 룰

- **게시**: 주 3편, 같은 영상을 릴스+쇼츠 동시 업로드 (제작 1회, 노출 2배)
- **측정**: 조회수보다 **프로필 클릭·DM 수**. DM 문의는 KPI 대시보드에 응답+1, 메모 "숏폼"
- **부스트(유료)**: 오가닉으로 반응 좋은 영상만 일 1만원 부스트 — 판단 기준은 [광고 가이드](광고-세팅-가이드.md)의 CPL 룰 그대로
- **댓글 문의**: 24시간 내 답 + DM 전환 ("업체명 알려주시면 샘플 만들어 드릴게요")
- 4주 해보고 프로필 클릭이 0에 수렴하면 훅(첫 문장)부터 교체
