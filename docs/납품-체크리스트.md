# 납품 체크리스트 — 고객 페이지 오픈 전 필수 확인

> 데모(가상 업체) 기반으로 만든 페이지를 실제 고객에게 납품하기 전, 아래를 전부 통과해야 한다.
> 특히 ⚖ 표시는 법적 문제(표시광고법)와 직결된다.

## ⚖ 법적 필수 — 가짜 정보 제거

- [ ] **데모의 가상 후기·별점 전부 삭제** — 실제 고객 후기만 게재. 없으면 후기 섹션 자체를 뺀다.
      (가짜 후기는 표시광고법 위반 — 고객과 나 모두 처벌 대상이 될 수 있다)
- [ ] "네이버 리뷰 4.9" 같은 수치는 **실제 확인 가능한 값**으로만 (없으면 삭제)
- [ ] "재방문율 92%" 등 근거 없는 통계 제거
- [ ] 데모 문구("데모용 가상 업체입니다" 등) 잔재 제거
- [ ] 의료기관(치과 등)은 의료광고 규제 주의 — 치료 효과 보장·최상급 표현("최고", "무통 보장") 금지

## 📞 연결 확인 — 버튼이 실제로 작동하는가

- [ ] 전화 버튼 → 실제 매장 번호로 발신되는지 폰에서 직접 테스트
- [ ] 카카오톡 버튼 → 고객의 실제 채널로 연결
- [ ] 예약 버튼 → 네이버예약/예약 페이지 실제 URL
- [ ] 주소·영업시간·가격표가 고객이 확인해준 최신 정보인지

## 📱 품질 확인

- [ ] 폰(세로)에서 전체 스크롤 — 깨짐·겹침 없음
- [ ] 오탈자 검수 (특히 상호명·가격·전화번호)
- [ ] 페이지 제목·검색 설명(meta)이 고객 업체명으로 교체됨
- [ ] 고객이 제공한 사진의 사용 허락 확인 (인터넷에서 퍼온 사진 금지)

## 📦 납품 절차

- [ ] 고객 확인용 링크 전달 → **서면(카톡) 승인** 받기 ("이대로 오픈할게요, 확인 부탁드립니다")
- [ ] 승인 후 배포 → 최종 URL 전달
- [ ] 잔금 요청 → 입금 확인 → 현금영수증 발급
- [ ] 후기 요청 + 유지보수 제안 ([전환 스크립트](영업-전환-스크립트.md) 5번)
- [ ] KPI 대시보드에 계약·매출 기록
- [ ] 납품물 사본을 `clients/업체명/` 에 보관 (gitignore 처리되어 있음)
