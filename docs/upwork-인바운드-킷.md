# Upwork 인바운드 킷 — 콜드메일의 반대편 엔진

> 영상 챕터 "Getting clients with Upwork"(00:27~00:57) 대응.
> 콜드메일은 응답을 기다리는 게임, Upwork는 **이미 "홈페이지 필요"라고 올린 사람**에게 응답하는 게임.
> 우리 데모 12종이 그대로 포트폴리오가 된다.

## 0. 왜 Upwork인가 (우리 상황)
- 수요가 이미 존재 → 첫 고객까지 콜드보다 빠른 경우가 많음.
- 해외(미·영·호주) 클라이언트가 대부분 → 우리 영어 데모(studio-en·salon-en·cafe-en)·$가격이 그대로 통함.
- 리뷰 몇 개만 쌓이면 인바운드가 자동으로 늘어남(복리).

## 4. 운영 규칙
- 하루 **커넥트(bid) 5~8개**, 개인화 한 줄 없는 지원 금지.
- 응답 오면 → 24시간 내 무료 샘플 제작(데모 복사, 상호 교체) → 링크 전달 = 다른 지원자 압도.
- 첫 5건은 **리뷰 확보가 목표** → 가격 낮춰도 OK, 대신 별점 5개 요청(후기 요청 스크립트 활용).
- Upwork 안에서 계약·결제(수수료 있지만 리뷰·에스크로 안전) → 신뢰 쌓인 뒤 반복 고객은 직거래.

## 5. KPI
- 주간: 지원 수 / 응답 수 / 샘플 제작 수 / 계약 수. KPI 대시보드에 "UPWORK" 메모로 분리 기록.
- 목표(4주): 지원 100+ → 응답 10+ → 계약 2~3.
