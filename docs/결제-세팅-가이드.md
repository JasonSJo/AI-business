# 결제 세팅 가이드 — 고객 돈을 받는 인프라

> Jason's Consulting이 고객에게 대금을 받기 위한 계좌·사업자·세금 세팅 순서.
> 은행·홈택스 절차는 본인 명의로만 가능하므로 아래 체크리스트를 직접 진행한다.
> (세법 기준은 바뀔 수 있으니 최종 확인은 홈택스 또는 세무사에게.)

---

## 0. 지금 당장 (첫 고객이 눈앞에 있다면)

사업자등록 전에도 합법적으로 받을 수 있다:

- **프리랜서 인적용역 (3.3% 원천징수)** — 고객이 사업자라면, 내 주민등록번호로 **3.3% 떼고** 지급받는 방식. 계약서/견적서에 "원천징수 3.3% 공제 후 지급" 명시. 내 개인 계좌로 수령 가능. 다음 해 5월 종합소득세 신고로 정산.
- 단, 이 방식은 **임시 통로**다. 반복 매출이 생기면(2~3건째부터) 사업자등록으로 전환한다 — 계속·반복적 사업은 등록 의무가 있고, 비용 처리와 신뢰 면에서도 등록이 유리하다.

---

## 1. 사업자등록 (무료, 온라인 30분)

1. **홈택스** (hometax.go.kr) → 신청/제출 → 사업자등록 신청(개인)
2. 입력값:
   - 상호: **Jason's Consulting** (한글 병기 가능: 제이슨스컨설팅)
   - 업종: **웹사이트 제작·관리** / 응용소프트웨어 개발·공급 / 광고대행 계열 중 실제 서비스에 맞는 것 (검색창에 "웹" 입력하면 후보가 나온다)
   - 사업장: 자택 주소 가능 (임대차 서류 불필요)
3. **간이과세 vs 일반과세** — 시작은 **간이과세** 추천:
   - 연 매출 1억 400만원 미만이면 유지 가능, 부가세 부담·신고가 훨씬 가볍다 (신고 연 1회, 1월)
   - 주의: 직전연도 매출 4,800만원 미만 간이과세자는 **세금계산서를 발급할 수 없다**. B2B 고객(병원·법인 등)이 세금계산서를 요구하면 **현금영수증(지출증빙용)** 발급으로 대부분 해결된다.
   - 법인·중견 고객 위주로 갈 계획이면 처음부터 일반과세 선택 고려.
4. 보통 당일~2일 내 등록증 발급.

## 2. 계좌 분리 (반나절)

- 사업자등록증이 나오면 **개인사업자 통장** 개설 — 토스뱅크·카카오뱅크는 비대면 10분 컷, 시중은행도 가능.
- **모든 매출·경비는 이 통장으로만.** 개인 생활비와 섞이면 5월 종소세 신고 때 지옥이 된다.
- 1인 간편장부 대상자는 사업용계좌 *신고* 의무는 없지만, 분리 자체는 무조건 하는 것이 좋다.
- 통장 개설 후 이 저장소의 **청구서 도구**(`tools/invoice/청구서.html`)에 계좌번호를 넣어두면 이후 모든 청구서에 자동 반영된다.

## 3. 결제 수단 3단계 (단계적으로 추가)

| 단계 | 수단 | 언제 | 비용 |
|---|---|---|---|
| **1단계 (지금)** | **계좌이체** + 현금영수증(지출증빙) 발급 | 첫 고객부터 | 0원 |
| **2단계 (매출 발생 후)** | **카드 결제 링크** — 토스페이먼츠 / 포트원 / 페이플 등에서 "링크 결제" 신청 → 카톡으로 링크 전송, 고객이 카드 결제 | 월 3건 이상부터 | 수수료 ~2.5–3.5% |
| **선택** | **크몽·숨고 플랫폼** | 초기 신뢰·후기 확보용 | 수수료 10–20% |

- 현금영수증 발급: 홈택스 → 조회/발급 → 현금영수증 발급 (고객 사업자번호로 "지출증빙용" 발급). 10만원 이상 현금거래는 요구 시 발급 의무.
- 카드 링크 결제를 열려면 **통신판매업 신고**가 필요할 수 있다 — 간이과세자 등 소규모는 면제 조건이 있으니 결제사 가입 절차에서 안내를 따르면 된다.

## 4. 대금 받는 표준 플로우 (계약~입금)

```
견적서 발송 → 구두/서면 확인 → 선금 50% 입금 확인 → 제작 착수
→ 시안 확인 → 납품 → 잔금 50% → 현금영수증/세금계산서 발급
→ KPI 대시보드에 매출 기록 → 후기 요청
```

- **선금 없이 착수하지 않는다.** 무료 샘플(데모)까지는 공짜, 실제 제작은 선금부터.
- 입금 확인 즉시 아래 템플릿으로 회신해 신뢰를 만든다.

### 입금 요청 메시지 (복붙용)

```
{대표님}, 진행 확정 감사합니다!

아래로 선금 입금해 주시면 바로 제작 시작하겠습니다.

· 금액: {선금액}원 (총 {총액}원의 50%)
· 계좌: {은행} {계좌번호} (예금주: {예금주})
· 완료 예정: 입금 확인 후 48시간 이내

입금 후 사업자번호(또는 휴대폰 번호) 알려주시면
현금영수증(지출증빙) 발급해 드립니다.
```

### 입금 확인 회신

```
{대표님}, 입금 확인했습니다. 감사합니다!
지금부터 제작 들어갑니다. {완료예정일}까지 시안 보내드릴게요.
현금영수증은 방금 발급했습니다 (홈택스에서 확인 가능).
```

## 5. 세금 달력 (놓치면 가산세)

| 시기 | 할 일 |
|---|---|
| 매 거래 | 현금영수증/세금계산서 발급, 경비 영수증 보관 |
| **1월** | 부가가치세 신고 (간이과세자 연 1회) |
| **5월** | 종합소득세 신고 (매출 커지면 세무사 기장 위임 고려 — 월 10만원 내외) |

- 매출·경비 기록은 **KPI 대시보드의 매출 입력**과 사업자 통장 내역이 원장이 된다.
- 연 매출 2,400만원 넘어가면 세무사 기장을 붙이는 게 시간 대비 이득이다.
