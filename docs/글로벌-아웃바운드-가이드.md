# 글로벌 아웃바운드 가이드 — 미국·일본 이메일 영업

> jasonsjo.github.io/AI-business(영어 루트 · /ja/ · /kr/)을 착륙 페이지로,
> 미국·일본 로컬 비즈니스에 이메일로 무료 샘플을 제안한다.
> 상품·가격·오퍼는 국내판과 동일 구조: **무료 샘플 먼저 → 48시간 → 마음에 들 때만 결제.**

## 0. 법적 기본 (이것만 지키면 합법적 콜드 이메일)

| 국가 | 법 | 지켜야 할 것 (템플릿에 이미 반영됨) |
|---|---|---|
| 🇺🇸 미국 | CAN-SPAM | 발신자 실명·소재지 표기, 제목 과장 금지, **수신거부 방법 명시**, 거부 시 재발송 금지 |
| 🇯🇵 일본 | 特定電子メール法 | 원칙 옵트인이나 **공개된 사업용 주소로의 B2B 제안은 가능** — 발신자 표기 + 수신거부 안내 필수 |

- 템플릿(us/jp)에 수신거부 문구와 발신자 표기가 들어 있으니 **지우지 말 것.**
- "unsubscribe" 회신이 오면 리드에서 영구 제거.

## 1. 리드 소스 (공개 정보만)

- **미국**: Google Maps("pilates studio austin"), Yelp — 웹사이트 없음/링크트리만 있는 곳. 이메일은 인스타 프로필·페이스북 페이지에 공개된 것만
- **일본**: Google Maps, 食べログ·ホットペッパービューティー에 등록됐지만 자체 사이트가 없는 곳
- 타겟 우선순위: 필라테스/요가 스튜디오 → 살롱 → 카페 (데모가 그대로 통하는 순서)
- 리드 수집기 그대로 사용 — industry 칸에 **`us` 또는 `jp`** 입력, channel은 `email`

## 2. 발송 시간대 (한국에서 보낼 때)

| 타겟 | 현지 좋은 시간 | 한국 시간 기준 |
|---|---|---|
| 미국 동부 | 화–목 08–10시 | **21–23시 (KST)** |
| 미국 서부 | 화–목 08–10시 | **새벽 01–03시 → 예약발송 권장** |

지메일 "보내기 예약"으로 현지 아침에 도착시키면 오픈율이 크게 달라진다.

## 4. 결제 수단 (해외 수금)

- **PayPal** (paypal.com 가입, 개인→비즈니스 업그레이드) — 미·일 모두 통용, 인보이스 발행 가능. 수수료 ~4-5%
- **Wise** — 수수료 낮음, USD/JPY 수취 계좌 제공. PayPal과 병행 추천
- 국내 계좌이체 안내는 해외 고객에게 사용 불가 — 견적서의 결제 안내를 PayPal 링크로 교체할 것
- 세무: 해외 매출도 사업소득 신고 대상. 부가세는 용역 수출로 영세율 적용 가능 — 매출 커지면 세무사 확인

## 5. 실행 플로우 (국내판과 동일한 도구)

```bash
# 리드 CSV: industry=us 또는 jp, channel=email, owner="there"(미국) / "御担当者"(일본)
cd tools/cold-email-generator
python3 generate.py global-leads.csv --sender Jason --base-url https://jasonsjo.github.io/AI-business/
# → 발송센터.html에서 "메일 열기" 클릭 = 받는사람·제목·본문 자동 입력 (지메일 예약발송 활용)
```

- 발송 한도 램프 동일: 1주차 10통/일 → 30통/일
- KPI 기록 메모: "US" / "JP" — 국가별 응답률 분리 추적
- 3일 무응답 → 짧은 팔로업 1회("Just floating this back up — want me to make that free sample?"). 그 이상은 금지

## 6. 응답 처리

- 응답 → 24시간 내 무료 샘플 제작 (studio-en config 복사, 상호·도시 교체 — 10분)
- 가격 제시는 [전환 스크립트](영업-전환-스크립트.md) 구조 그대로, 금액만 $/¥
- 시차 콜 부담 → "5분 통화" 대신 **Loom 영상 or 이메일 왕복** 기본
