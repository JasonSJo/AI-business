## 4. 크몽 — 서비스 등록 문구

- **제목**: 예약받는 랜딩페이지, 48시간 완성 — 무료 샘플 먼저 보고 결정하세요
- **카테고리**: IT·프로그래밍 > 홈페이지 제작 (또는 랜딩페이지)
- **요약 (3줄)**:
  - 결제 전에 실물 샘플부터 보여드립니다 (업계에서 저희만 합니다)
  - 전화·카톡 원터치 예약 버튼, 모바일 최적화 기본
  - 치과·살롱·카페·필라테스 등 업종별 전문 디자인
- **패키지**:
  | | STANDARD | DELUXE | PREMIUM |
  |---|---|---|---|
  | 가격 | 490,000원 | 690,000원 | 990,000원 |
  | 구성 | 1페이지 + 수정 2회 | + 리뷰·오시는길 고도화, 수정 4회 | + 유지보수 3개월, 사진 보정 |
  | 기간 | 2일 | 3일 | 4일 |
- **상세 첫 문단**: "말보다 실물이 빠릅니다. 업종별 실제 데모를 먼저 보세요: [데모 링크]. 주문 전 채팅으로 업체명만 알려주시면, 사장님 가게 이름이 들어간 샘플을 무료로 만들어 보여드립니다."
- **FAQ**: 수정 횟수? (패키지별 2~4회) · 도메인? (기본 무료 주소 제공, 커스텀 도메인 연결 지원) · 유지보수? (월 33,000원 선택)
