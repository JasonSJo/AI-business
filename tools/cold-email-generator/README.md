# 콜드 아웃리치 메시지 생성기

리드 CSV → 업종·채널별 개인화 메시지 대량 생성. **외부 의존성 없음** (Python 표준 라이브러리만).

## 사용법

```bash
cd tools/cold-email-generator
# 배포 사이트가 있으면 --base-url: 업종별 데모 링크가 자동으로 붙는다
python3 generate.py leads.sample.csv --sender 제이슨 \
    --base-url https://jasons-consulting.com/

# 배포 전이면 단일 링크로
python3 generate.py leads.sample.csv --sender 제이슨 --demo-url https://내데모주소
```

출력:
- **`out/발송센터.html`** — 브라우저로 열어 **클릭 발송**: 이메일 리드는 "메일 열기"(제목·본문 자동 입력), DM 리드는 "본문 복사". 완료 체크 후 "KPI JSON 내보내기" → 대시보드 "JSON 가져오기"로 오늘 발송량이 자동 기록된다.
- `out/NNN-업체명.txt` — 리드별 발송용 메시지 (수동 발송용)
- `out/전체목록.md` — 발송/응답 체크리스트

`--base-url` 지정 시 업종→데모 매핑: dental→`dental-clinic/`, salon→`hair-salon/`, cafe→`cafe/`, pilates→`pilates-studio/` (그 외는 허브 루트).

## 리드 CSV 작성법

| 컬럼 | 내용 |
|---|---|
| `business` | 업체명 (필수) |
| `owner` | 호칭 — 원장님/실장님/사장님 (비우면 "대표님") |
| `industry` | `dental` `salon` `cafe` `pilates` — 그 외/공란은 default 템플릿 |
| `channel` | `email` 또는 `dm` (공란은 email) |
| `observation` | **개인화 한 줄** — 응답률을 결정하는 가장 중요한 칸. "리뷰 180개인데 홈페이지가 없어서요" |
| `contact` | 이메일/인스타 핸들 (체크리스트에 표시) |
| `demo_url` | 이 리드에게 보여줄 데모 (공란이면 `--demo-url` 값) |

`leads.sample.csv`를 복사해 시작하면 된다.

## 리드 수집 루틴 (하루 30분)

1. 네이버 지도/인스타에서 타겟 업종 검색 (예: "마포 치과")
2. **웹사이트 없거나 예약 링크 없는 곳**만 리스트업 → 그게 리드
3. 각 업체에서 관찰 한 줄 메모 (리뷰 수, 인스타 팔로워, 없는 것)
4. CSV에 추가 → 생성기 실행 → 하루 20~40건 발송
5. `전체목록.md` 체크리스트로 발송/응답 추적

## 템플릿 수정

`templates.json`에서 업종·채널별 문구를 수정한다. 플레이스홀더:

- `{업체명}` `{대표님}` `{관찰}` `{데모링크}` `{이름}`
- `{업체명을}` `{업체명이}` `{업체명은}` — 받침에 맞는 조사 자동 선택 (치과**를** / 살롱**을**)

응답률이 낮으면 첫 문장(훅)부터 A/B 테스트할 것 — [30일 로드맵](../../docs/30일-수익-실행-로드맵.md) 참고.

## 주의

- `observation`이 빈 리드는 메시지 상단에 경고가 붙는다. **개인화 없이 보내지 말 것.**
- 스팸 대량발송이 아니라 1:1 개인화 제안이 목적이다. 하루 발송량을 무리하게 늘리기보다 관찰의 질을 높이는 게 응답률에 유리하다.

## 지메일 발송 안전 수칙 (계정 제한 방지)

발신 계정: wheldfo23@gmail.com — 지메일은 콜드 발송을 과하게 하면 **계정을 일시 제한**한다. 아래 램프를 지킬 것:

| 기간 | 일일 발송 상한 |
|---|---|
| 1주차 | **10통** |
| 2주차 | 20통 |
| 3주차~ | 30통 (지메일 콜드 발송의 실질 상한) |

- 발송 간격을 두고 보낼 것 (한 번에 몰아서 X — 발송센터에서 자연스럽게 분산됨)
- **같은 문장 복붙 대량발송 금지** — 개인화 한 줄이 스팸 필터 회피에도 핵심
- 수신자가 "그만 보내라"고 하면 즉시 리드에서 제거
- 30통/일 이상 규모가 필요해지면: 자체 도메인 메일(구글 워크스페이스 등) + 발송 도구로 이전 — 그 전까지는 이메일보다 **인스타 DM·전화 비중**을 높이는 게 안전하다
- 반송(bounce)이 연속 3건 나오면 그날 발송 중단 (잘못된 주소 수집 신호)
