# 랜딩페이지 데모 — 이제 전부 "맞춤(bespoke)" HTML

2026-07-23부터 demo/ 아래 11개 데모는 **각 매장 성격에 맞춰 개별 디자인된 손수 작성 HTML**이다.
더 이상 하나의 template.html에서 자동 생성하지 않는다 (사장님 요청: "각각 다른 디자인").

- 원본 콘텐츠(상호·가격·후기·위치)는 `_bespoke/*.json.bak` 에 보존되어 있다 — 문구 수정 시 참고용.
- **generate.py 로 이 데모들을 재생성하지 마라** — 맞춤 디자인이 template.html 버전으로 덮여 사라진다.
- 새 고객 페이지를 만들 땐: 업종이 가장 비슷한 demo/ 페이지를 복사 → 상호·가격·사진만 교체.
- template.html + generate.py 는 빠른 초안이 필요할 때를 위해 남겨둔다.
