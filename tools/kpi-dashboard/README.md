# KPI 대시보드

아웃리치 퍼널(발송 → 응답 → 미팅 → 계약)을 매일 기록하고 **이번 주 병목**을 자동으로 짚어주는 대시보드.
단일 HTML 파일 — 서버·설치·로그인 불필요, 데이터는 브라우저 localStorage에만 저장.

## 사용법

```bash
# 브라우저에서 파일을 직접 열거나
open tools/kpi-dashboard/index.html   # (macOS) / 윈도우는 더블클릭

# 로컬 서버로 열기
cd tools/kpi-dashboard && python3 -m http.server 8893
# → http://localhost:8893
```

처음이면 **"샘플 데이터 채우기"** 버튼으로 6주치 가짜 데이터를 넣어 화면을 익힌 뒤, **"전체 삭제"** 하고 실제 기록을 시작하면 된다.

## 매일 하는 일 (30초)

1. 오늘 날짜로 발송/응답/미팅/계약 건수 입력 (매출·메모는 있을 때만)
2. "기록 추가" — 끝.

## 화면 구성

| 영역 | 내용 |
|---|---|
| **이번 주 타일** | 발송·응답·미팅·계약 + 주간 목표 대비 / 전환율 vs 기준 |
| **주간 추이** | 주별 발송·응답 막대 차트 (호버 시 상세) |
| **퍼널 & 병목** | 단계별 전환율 + 기준(응답률 10% · 응답→미팅 35% · 미팅→계약 40%) 대비 가장 낮은 구간을 병목으로 표시 |
| **병목 처방** | 병목별 이번 주 액션 제안 (훅 A/B, 24시간 회신, 무료 샘플 선제작) |
| **이번 달 매출** | 목표 대비 진행률 (목표는 화면에서 수정) |
| **기록 테이블** | 최근 기록 확인·삭제 |

병목 기준 전환율은 [30일 로드맵](../../docs/30일-수익-실행-로드맵.md)의 수치를 따른다.

## 데이터 관리

- **JSON 내보내기** — 백업 파일 다운로드 (주 1회 권장)
- **JSON 가져오기** — 다른 기기/브라우저로 이전
- 데이터는 이 브라우저에만 있다. 브라우저 데이터 삭제 시 함께 지워지므로 백업 습관을 들일 것.

## 차트 색상에 대해

차트 팔레트는 dataviz 검증기를 통과한 조합이다 (크림 배경 `#F4EFE6` 기준):

- 발송 `#00806A` / 응답 `#CC5E20` — 색약 시뮬레이션 ΔE 8.8 (기준 8 이상), 대비 3:1 이상
- 퍼널 램프 `#54B49D → #005B4C` — 단일 색상 밝기 단계, 서수 검증 통과
- 병목 표시는 색만이 아니라 ⚠ 아이콘 + 텍스트 라벨 동반
