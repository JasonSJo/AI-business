# 데모 랜딩페이지 — 고요 필라테스 (가상 스튜디오)

영업용 **데모 상품**입니다. 실제 존재하지 않는 가상 스튜디오("고요 필라테스")로 만들었으며,
잠재 고객에게 "이런 걸 만들어 드립니다"를 보여주는 **첫 영업 무기**입니다.

> 영상의 *Day 2: 가짜 사업용 사이트를 만들어 무료 배포하라* 단계에 해당합니다.

## 무엇을 보여주는가

- 모바일 최적화(반응형) 1페이지 랜딩
- 상단 고정 헤더 + 스크롤 애니메이션
- 히어로 / 강점 3가지 / 프로그램·가격표 / 후기 / 오시는 길(지도) / 푸터
- **모바일 하단 고정 CTA 바** — 전화 · 카카오톡 · 예약 (소상공인 전환의 핵심)
- 외부 이미지 없이 자체 완결(SVG·그라디언트) → 어디에 올려도 항상 렌더링

## 로컬에서 보기

```bash
cd demo/pilates-studio
python3 -m http.server 8891
# 브라우저에서 http://localhost:8891
```

## 새 고객용으로 바꾸는 법 (5분)

`index.html`에서 아래 항목만 찾아 바꾸면 다른 업종으로 재사용됩니다.

| 바꿀 것 | 위치(검색어) |
|---|---|
| 상호명 | `고요 필라테스` |
| 슬로건/문구 | `하루 한 시간` / `.lede` 문단 |
| 프로그램·가격 | `price-grid` 섹션 |
| 후기 내용 | `rev-grid` 섹션 |
| 주소·시간·전화 | `loc-row` 항목들 |
| 전화 연결 | `href="tel:0200000000"` → 실제 번호 |
| 카카오 채널 | `카톡` 버튼의 `href="#"` → `http://pf.kakao.com/_채널ID` |
| 네이버 예약 | `체험 예약` 버튼 `href="#price"` → 네이버 예약 URL |
| 색상 테마 | `:root` 의 `--pine` `--clay` 등 CSS 변수 |

> 업종만 바꾸면 병원·미용실·카페·공방 등에도 그대로 응용 가능합니다. 색상·문구·아이콘만 교체하세요.

## 무료 배포 방법 (택 1)

- **Netlify Drop** — <https://app.netlify.com/drop> 에 `pilates-studio` 폴더를 드래그하면 즉시 URL 생성
- **GitHub Pages** — 저장소 Settings → Pages → 이 폴더 배포
- **Vercel** — `vercel` CLI 또는 대시보드에서 폴더 임포트
- **Cloudflare Pages** — 저장소 연결 후 자동 배포

배포한 URL을 콜드 이메일/DM에 첨부하면 "실제 결과물"이 되어 응답률이 크게 오릅니다.

## 영업에 쓰는 법

1. 이 데모를 무료 호스팅에 올려 **살아있는 링크** 확보
2. 타겟 매장(예약 링크 없는 병원·미용실 등)에게 콜드 이메일 발송 시 이 링크 첨부
3. 관심 보이면 → 그 매장 이름·사진으로 **맞춤 데모** 30분 만에 제작해 재전송
4. 계약 → 실제 정보로 채우고 배포 → 후기 요청
